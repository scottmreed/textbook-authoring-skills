# Historical topic-package QA snapshots

These files are dated review evidence from the textbook-authoring process.
They are **not statements about the current released textbook**, current
deployment, current link health, or current publication readiness.

Each report records what reviewers found, verified, or recommended at the date
shown in that artifact. A report can therefore mention a major revision,
blocked feature, live defect, old test count, renderer behavior, or product
implementation detail that was later changed elsewhere. Do not infer current
release status from an individual finding or from the baseline verdict in the
index.

Use [`CHAPTER_REVIEW_STATUS.md`](CHAPTER_REVIEW_STATUS.md) as the concise index
of the saved snapshot dates and baseline assessments. Read an individual
`chapter-review.md` or `chapter-review.json` only as historical evidence, with
its date and correction context. The detailed reports are deliberately retained
for auditability; this wrapper and the index are the current navigation layer.

Some records retain selected source-path fragments, component names, vendor
references, identifiers, and implementation observations because they explain
the original QA finding. They have not been refreshed or normalized into a
portable specification.
